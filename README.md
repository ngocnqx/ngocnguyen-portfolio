# ngocnguyen-portfolio

Personal portfolio of Ngoc Nguyen, Dickinson College (Data Analytics, Finance & Quantitative Economics, May 2028).

Live site: https://ngocnqx.github.io/ngocnguyen-portfolio/

## Structure
- `index.html`: the whole site in one file (styles, content, and profile photo are built in)
- `img/`: project screenshots referenced on project pages (add as you go)

## Editing
Experience, leadership, and projects live in the `JOBS`, `LEADERSHIP`, and `PROJECTS` lists near the bottom of `index.html`.
Edit the text there, commit, and GitHub Pages redeploys automatically in about a minute.
